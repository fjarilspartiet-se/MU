# Contemplative Practices Guide
## Developing Inner Understanding

### Foundation Practices

#### 1. Basic Presence Practice
**Purpose**: Develop stable, clear attention

**Structure**:
1. **Preparation** (2-3 minutes)
   - Find comfortable position
   - Connect with body
   - Set clear intention

2. **Practice** (10-15 minutes)
   ```markdown
   Phases:
   1. Settling (2-3 minutes)
      - Allow body to settle
      - Let breath find natural rhythm
      - Notice present experience
   
   2. Main Practice (5-10 minutes)
      - Rest attention with breath
      - Notice when mind wanders
      - Return gently to breath
   
   3. Integration (2-3 minutes)
      - Open to whole experience
      - Notice overall state
      - Transition mindfully
   ```

3. **Documentation**
   ```markdown
   Practice Session:
   Date: [Date]
   Duration: [Time]
   
   Quality of Practice:
   - Attention stability:
   - Notable experiences:
   - Challenges:
   - Questions arising:
   ```

#### 2. Body Awareness Practice
**Purpose**: Develop embodied presence and sensitivity

**Structure**:
1. **Body Scan** (15-20 minutes)
   - Systematic attention through body
   - Notice sensations and qualities
   - Develop somatic awareness

2. **Integration**
   ```markdown
   Observation Areas:
   - Physical sensations
   - Energy/vitality
   - Emotional tone
   - Mental state
   
   Integration Notes:
   - Key observations
   - Patterns noticed
   - Questions arising
   ```

### Intermediate Practices

#### 1. Contemplative Inquiry
**Purpose**: Unite clear attention with investigation

**Framework**:
1. **Setup Phase** (5 minutes)
   - Establish stable presence
   - Connect with question/topic
   - Open to direct experience

2. **Investigation Process** (20-30 minutes)
   ```markdown
   Areas of Focus:
   1. Direct Experience
      - Immediate sensations
      - Thoughts/emotions
      - Energy patterns
   
   2. Understanding
      - Notice assumptions
      - Track understanding
      - Allow insights
   
   3. Integration
      - Connect insights
      - Note applications
      - Document questions
   ```

#### 2. Open Awareness Practice
**Purpose**: Develop natural presence and clarity

**Structure**:
1. **Practice Phases**
   ```markdown
   1. Settling (5-10 minutes)
      - Allow natural settling
      - Notice present state
      - Rest in awareness
   
   2. Main Practice (20-30 minutes)
      - Rest in natural awareness
      - Notice what appears
      - Allow experience
   
   3. Integration (5-10 minutes)
      - Notice understanding
      - Allow application
      - Document insights
   ```

2. **Documentation Framework**
   ```markdown
   Session Notes:
   - Quality of presence
   - Key experiences
   - Insights arising
   - Questions emerging
   ```
